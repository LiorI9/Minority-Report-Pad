# Minority Report Pad — PRD

> **למה ולמי.** איך זה בנוי: [ARCHITECTURE.md](ARCHITECTURE.md). למה החלטנו כך: [adr/](adr/).

## 1. חזון
תוסף לכרום שמאפשר לשלוט בטאב באמצעות מחוות ידיים מול מצלמה, בהשראת הטרקפד של מק.

## 2. משתמש ותרחיש
- **מציג שעומד מול קהל** ושולט בדפדפן בלי מקלדת ועכבר.
- **0.1 מכוון לתרחיש פודיום** — כ-1 מטר מהמצלמה. מציג שמסתובב על הבמה (2–3 מ') — בהמשך ([ADR-009](adr/009-distance-validation.md)).

## 3. מודל אינטראקציה
### שתי ידיים ([ADR-001](adr/001-two-hand-model.md))
- **יד ייחוס** — עוגן + מצמד. מורמת ופתוחה = פעיל; מורדת או אגרוף = מושהה. כך מציג יכול לדבר עם הידיים בלי לחיצות בטעות.
- **יד תנועה** (היד הדומיננטית) — מזיזה את הסמן ביחס ליד הייחוס.

### מספר אצבעות ביד התנועה = פעולה ([ADR-002](adr/002-mac-trackpad-mapping.md))
| אצבעות | פעולה | סמן |
|---|---|---|
| 5 (יד פתוחה) | תזוזת סמן | טבעת צהובה |
| 1 | לחיצה שמאלית | נקודה כתומה |
| 2 | בלי תנועה = לחיצה ימנית; עם תנועה = גלילה טבעית | גלולה כחולה ↕ |
| 3 | החלקה אופקית מהירה = החלפת טאב; החזקה = גרירה | עיגול ירוק עם חצי תזוזה; מלא בזמן גרירה |
| אגרוף | מנוחה | עיגול אפור מקווקו |

### זום ([ADR-014](adr/014-two-hand-zoom.md))
יד הייחוס עושה **V** (2 אצבעות), ואז מרחיקים או מקרבים את הידיים: הרחקה = זום פנימה, קירוב = זום החוצה. זה זום של הדפדפן, כמו Cmd+ ו-Cmd−. יד ייחוס פתוחה חוזרת למצב רגיל. הסמן הופך לזכוכית מגדלת עם אחוז הזום.

### הצגת ידיים ([ADR-015](adr/015-hands-overlay.md))
אפשר להציג על הדף שלד שקוף של שתי הידיים, כדי שהקהל יראה מה המציג עושה. מתג בפופאפ, כבוי כברירת מחדל.

## 4. מכשירים
- **דסקטופ (כרום)** — יעד ראשי.
- **Pixel 7a ו-iPhone** — דף הבדיקות בלבד (תוספים לא רצים במובייל). ✅ אומת שעובד.

## 6. מדדי הצלחה
- **זיהוי:** 90% זיהוי נכון של מספר האצבעות במרחק 1 מ'. סטטוס: עבר באימות ויזואלי ב-Mac, Pixel ו-iPhone; מדידה כמותית נדחתה.
- **ביצועים:** FPS ו-latency על Pixel — למדוד (הערכה: 15–30 FPS).

## 7. רודמפ
### 0.1 — MVP: כל מיפוי המק — 🚧 שלד מקצה לקצה בנוי, ממתין לבדיקה עם מצלמה
- מצמד + סמן וירטואלי; לחיצה, ימנית, גלילה, גרירה, החלפת טאב.
- הזרקה סינתטית + `chrome.tabs` בלבד, בלי debugger.
- Offscreen + תצוגה מקדימה קטנה; דף הגדרות לאישור מצלמה.
- קליברציה בסיסית: רגישות סמן + יד דומיננטית.
- הגדרות תחושה: עוצמת גלילה, גלילה טבעית או הפוכה, כיוון ההחלקה בין טאבים.
- **זום בשתי ידיים** (V ביד הייחוס + מרחק). הוקדם מ-0.3 לבקשת המשתמש.
- **הצגת ידיים** על הדף (מתג).

### 0.2
- מצב אמין (`chrome.debugger`) לפי אתר, בקליק אחד ([ADR-003](adr/003-hybrid-input-injection.md)).

### 0.3
- זום סביב הסמן (צביטה אמיתית דרך `chrome.debugger`), כשמצב ה-debugger מוכן.
- התאמה אישית מלאה: הדרכה ראשונית, מיפוי מחוות מותאם.

### לא בתכנון כרגע
- קיצורי מצגות ייעודיים, פרסום בחנות כרום, מצלמה מרוחקת (טלפון כמצלמה).
