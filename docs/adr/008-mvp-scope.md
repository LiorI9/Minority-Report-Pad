# ADR-008: תכולת 0.1: כל מיפוי המק + קליברציה בסיסית

- **סטטוס:** מאושר
- **תאריך:** 2026-11-06

## הקשר
צריך MVP שמציג אמיתי יכול לעמוד איתו מול קהל.

## החלטה
0.1 כולל את כל מיפוי המק (ADR-002) בלי debugger, וקליברציה בסיסית: רגישות ויד דומיננטית. 0.2 = debugger לפי אתר. 0.3 = זום בשתי ידיים והתאמה אישית מלאה.

## חלופות שנשקלו
- **מציג מינימלי** (בלי ימנית וגרירה).
- **ספייק טכני קודם**.
- **מינימלי + קיצורי מצגות**.

## השלכות
- 0.1 גדול יותר, וגרירה שבירה עד 0.2.
- משתמש שמאלי לא נתקע עם מערכת ימנית.
