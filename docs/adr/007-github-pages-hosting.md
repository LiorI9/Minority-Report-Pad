# ADR-007: אירוח ב-GitHub Pages, ריפו ציבורי

- **סטטוס:** מאושר
- **תאריך:** 2026-11-06

## הקשר
גישה למצלמה מחייבת HTTPS, והדף צריך לעבוד גם בטלפון.

## החלטה
ריפו ציבורי, פרסום ל-GitHub Pages ב-GitHub Actions מכל push ל-`main`.

## חלופות שנשקלו
- **Firebase Hosting** — דורש פרויקט והרשאות.
- **Vercel / Netlify** — עוד שירות לחבר.
- **HTTPS מקומי בלבד** — אזהרת תעודה בטלפון, בלי כתובת קבועה.
