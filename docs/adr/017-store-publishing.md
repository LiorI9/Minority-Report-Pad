# ADR-017: פרסום ב-Chrome Web Store — Unlisted, עם השם הנוכחי

- **סטטוס:** מאושר
- **תאריך:** 2026-11-09
- **משנה:** את "פרסום בחנות — לא בתכנון כרגע" ב-PRD

## הקשר
המשתמש רוצה להפיץ את התוסף דרך החנות, ולא רק דרך Load unpacked. לתוסף יש הרשאות רחבות (`<all_urls>`) ושימוש במצלמה, ושמו מבוסס על שם של סרט.

## החלטה
- **Unlisted:** בחנות, אבל לא מופיע בחיפוש. התקנה דרך קישור, עם עדכונים אוטומטיים.
- **השם "Minority Report Pad" נשאר.** הסיכון לדחייה או לתלונת קניין רוחני מתקבל ביודעין.
- **חומרי הגשה ב-`docs/store/`:** אייקונים, 3 צילומי מסך, אריחי קידום, טקסטים והצדקות להרשאות. מדיניות הפרטיות מתפרסמת ב-GitHub Pages.
- **צמצום הרשאות:** `tabs` הוסרה. היא לא נחוצה למזהי טאבים, לאינדקסים ולזום.

## חלופות שנשקלו
- **ציבורי** — מוקדם, לפני שמודל המחוות הוכח עם משתמשים.
- **Private (בודקים מורשים)** — דורש לנהל רשימת מיילים.
- **שם חדש לחנות בלבד, או לכל הפרויקט** — נדחה לבקשת המשתמש.

## השלכות
- בדיקה ארוכה יותר בגלל `<all_urls>`.
- אם השם יידחה: משנים את `name` ב-`wxt.config.ts` ובטקסטים, בלי שינוי בקוד.
- כל גרסה חדשה בחנות דורשת להעלות את `version` ולשלוח שוב לבדיקה.
