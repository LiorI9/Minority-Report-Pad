# ADR-002: מיפוי אצבעות כמו טרקפד מק

- **סטטוס:** מאושר
- **תאריך:** 2026-11-06

## הקשר
צריך מיפוי מספר אצבעות → פעולה שמשתמשי מק מכירים, בלי ללמוד שפה חדשה.

## החלטה
5 = תזוזה, 1 = לחיצה שמאלית, 2 = לחיצה ימנית (בלי תנועה) או גלילה (עם תנועה), 3 = גרירה (החזקה) או החלפת טאב (החלקה מהירה), אגרוף = מנוחה.

## חלופות שנשקלו
- **מותאם למציג** (1 = לחיצה, 2 = גלילה, 3 = מצביע לייזר) — בלי לחיצה ימנית.
- **לחיצה מול החזקה לכל מספר** — 6 פעולות, עומס קוגניטיבי.
- **מצבים שנבחרים ביד הייחוס** — מורכב.

## השלכות
- מוכר מיד למשתמשי מק.
- 2 ו-3 אצבעות מכפילים תפקיד, ולכן המנוע צריך להבחין בין תנועה לחוסר תנועה ובין מהיר לאיטי (ADR-010).
