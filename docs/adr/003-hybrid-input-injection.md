# ADR-003: הזרקת קלט היברידית; debugger לפי אתר

- **סטטוס:** מאושר
- **תאריך:** 2026-11-06

## הקשר
תוסף לא יכול להזיז את סמן מערכת ההפעלה. אירועים סינתטיים מסומנים `isTrusted: false` ויש אתרים שמסננים אותם. `chrome.debugger` מייצר אירועים אמיתיים, אבל מציג פס אזהרה בראש המסך, מול הקהל, ודורש הרשאה מפחידה.

## החלטה
ברירת מחדל: סמן וירטואלי + אירועים סינתטיים, ופעולות דפדפן דרך `chrome.tabs` ו-`scrollBy`. מצב `chrome.debugger` נדלק בקליק אחד לפי אתר (0.2), עם הרשאה אופציונלית.

## חלופות שנשקלו
- **debugger תמיד** — פס האזהרה מול הקהל.
- **מעבר אוטומטי ל-debugger** — מסובך למימוש ומפתיע.
- **אפליקציה נלווית (Native Messaging)** — התקנה נוספת, כבר לא רק תוסף.

## השלכות
- רוב הפעולות עובדות בלי debugger (אומת ב-Test Bed).
- HTML5 Drag & Drop לא יעבוד עד 0.2.
