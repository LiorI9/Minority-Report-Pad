# ADR-011: החלפת תוויות ימין/שמאל של MediaPipe

- **סטטוס:** מאושר
- **תאריך:** 2026-11-06

## הקשר
MediaPipe מסווג ימין ושמאל בהנחה שהתמונה מראתית (סלפי). אנחנו מעבירים לו את הפריים הגולמי מהמצלמה.

## החלטה
כברירת מחדל התוויות מוחלפות כדי לקבל את היד האמיתית של המשתמש. ניתן לביטול בכיול.

## חלופות שנשקלו
- **להעביר פריים מראתי** — עלות עיבוד נוספת.
- **תפקידים לפי מיקום במסך** — נשבר כשהידיים מצטלבות.

## השלכות
- **טרם אומת מול משתמש עם מצלמה.**
