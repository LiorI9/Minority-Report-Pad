# ADR-006: Test Bed לפני התוסף, מנוע משותף במונוריפו

- **סטטוס:** מאושר
- **תאריך:** 2026-11-06

## הקשר
רוב הסיכון הוא בזיהוי ובתחושת המחוות, לא בצנרת של התוסף. צריך מקום לנסות ולכייל מהר, ואחר כך דף מטרה לבדיקת התוסף.

## החלטה
דף בדיקות (Vite) נבנה ראשון. מנוע המחוות הוא חבילת TypeScript טהורה ב-`packages/gesture-engine`, משותפת לדף ולתוסף, במונוריפו אחד.

## חלופות שנשקלו
- **קובץ HTML יחיד** — מהיר, אבל המנוע היה נכתב מחדש בתוסף.
- **שני דפים נפרדים** (מעבדה ומטרות).
- **להתחיל ישר בתוסף**.

## השלכות
- המנוע נבדק ביחידה ובדפדפן אמיתי, גם במובייל.
- `SyntheticInput` של הדף הוא אב-טיפוס של ה-content script.
