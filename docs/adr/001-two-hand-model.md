# ADR-001: מודל שתי ידיים: יד ייחוס כעוגן ומצמד

- **סטטוס:** מאושר; ההשהיה באגרוף הוחלפה בהורדת היד ב-[ADR-016](016-fist-zoom-lower-to-pause.md)
- **תאריך:** 2026-11-06

## הקשר
מציג עומד מול קהל וזז. צריך קואורדינטות יציבות ודרך להבדיל בין מחווה מכוונת לבין תנועות ידיים טבעיות בזמן דיבור ("מגע מידאס").

## החלטה
שתי ידיים. יד התנועה מזיזה את הסמן ומבצעת פעולות. יד הייחוס משמשת עוגן (הסמן מחושב יחסית אליה) ומצמד: מורמת ופתוחה = פעיל, מורדת או אגרוף = מושהה.

## חלופות שנשקלו
- **עוגן בלבד** — לא פותר את מגע מידאס.
- **מצמד ומקשי קיצור ביד הייחוס** — מורכב מדי ל-0.1.
- **צביטה בשתי ידיים לזום** — נדחה ל-0.3.

## השלכות
- אין לחיצות בטעות כשהמצמד סגור.
- התנועה יחסית, ולכן עמידה לתזוזת הגוף.
- שתי ידיים מורמות מעייפות (סיכון פתוח).
